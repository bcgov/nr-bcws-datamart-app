# MCP Server Connect supported AI tools to BC Wildfire Service weather data using the Model Context Protocol (MCP). The MCP server allows compatible AI tools to access Weather DataMart information, including weather observations and weather station information. Once connected, you can ask questions about the data using natural language. For definitions of weather station information and weather measurements, see About weather stations and About weather data. ## On this page - [Getting started](about-mcp#getting-started) - [MCP server endpoint](about-mcp#mcp-server-endpoint) - [Available data](about-mcp#available-data) - [Available tools](about-mcp#available-tools) - [Connect an MCP client](about-mcp#connect-an-mcp-client) - [Example prompts](about-mcp#example-prompts) - [Using the MCP server](about-mcp#using-the-mcp-server) - [Troubleshooting](about-mcp#troubleshooting) - [Learn more about MCP](about-mcp#learn-more-about-mcp) ## Getting started The Model Context Protocol (MCP) is an open standard that allows AI applications and other compatible tools to connect to external data sources. The Weather DataMart MCP server provides read-only access to Weather DataMart data. You can use an MCP-compatible client to ask questions about the data without writing REST or GraphQL queries. For example, after connecting the MCP server, you could ask: `How many weather stations are currently active?` or: `Show me the five highest daily temperature readings.` The AI client determines which MCP tools to use to retrieve the information needed to answer your question. ## Authentication No authentication is required. ## MCP server endpoint `https://container-app-api-yujhzooydm766.bluewater-fbba4d31.canadacentral.azurecontainerapps.io/mcp` The way you add an MCP server depends on the client you are using. Refer to your client's documentation for instructions on adding a remote MCP server. ## Available data The MCP server provides access to the following Weather DataMart information: Data | Description - | --- Hourly weather | Hourly weather observations and measurements from weather stations. Daily weather | Daily weather measurements and fire weather indices. Weather stations | Weather station information, including station locations and metadata. Organization units | Fire Centre and Fire Zone organization information. ## Available tools The MCP server provides tools that allow compatible AI clients to discover and query Weather DataMart data. Tool | Description - | --- `describe-entities` | View the available data entities and their schemas. `read-records` | Retrieve records and apply filters. `aggregate-records` | Calculate counts, averages, sums, minimums and maximums. ## Read-only access The Weather DataMart MCP server provides read-only access to weather data. It cannot be used to create, update or delete Weather DataMart records. ## Connect an MCP client To use the MCP server, add the Weather DataMart MCP endpoint to an MCP-compatible client. ### Visual Studio Code Add the Weather DataMart MCP server to your Visual Studio Code MCP configuration: {{' { "servers": { "bcws-weather": { "url": "[MCP server endpoint]" } } } '}} After saving the configuration, follow the instructions in Visual Studio Code to start or enable the MCP server. [Learn how to use MCP servers in Visual Studio Code]() ### Other MCP clients The Weather DataMart MCP server can be used with clients that support remote MCP servers. Configuration varies by client. Refer to the documentation for your MCP client and use the MCP server endpoint provided above. ## Example prompts Once connected, you can ask your AI assistant questions about Weather DataMart data. For example: To ask about... | Try something like... - | ---- Weather stations | `How many weather stations are currently active?` Station locations | `List active weather stations in Fire Zone 50 with their coordinates.` Hourly weather | `What is the average wind speed from hourly observations today?` Daily weather | `Show me the five highest daily temperature readings.` Precipitation | `Show daily precipitation by station for the last seven days.` Available data | `What weather data can I access?` ## Using the MCP server The MCP server makes it easier to explore Weather DataMart data using natural language, but responses generated by an AI tool should still be interpreted with appropriate care. The information returned depends on the question asked, the available Weather DataMart data and how the connected AI tool uses the MCP tools. To get more precise results: - Be specific about the weather measurement you want. - Include a station, Fire Centre or Fire Zone when relevant. - Include the time period you are interested in. - Ask for the units or fields you need when they are important. For example, instead of: `What was the weather like?` ask: `What were the hourly temperature, relative humidity and wind speed readings for [station] yesterday?` ## Troubleshooting If your AI client cannot connect to the MCP server: - Confirm that the MCP server endpoint is entered correctly. - Confirm that your client supports remote MCP servers. - Check that the MCP server is enabled in your client. - Restart or reconnect the MCP client after changing its configuration. - Refer to your client's MCP documentation. ## Learn more about MCP New to MCP?
