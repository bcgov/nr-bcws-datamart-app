## `/daily_weather` Returns daily weather data derived from the noon hourly observation. Daily data includes weather measurements, precipitation accumulated over the previous 24 hours, fire weather indices when available and danger class. ### Request GET /daily_weather ### Attributes This endpoint returns records containing these attributes. These attributes can also be used to filter the records in the request.
